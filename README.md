# عدّاد حبنا 💍

صفحة ويب رومانسية لمصطفى ومنة الله، بتعدّ الأيام لحد يوم الفرح (١٥ يوليو ٢٠٢٧).

## فيها إيه
- ساعة رملية وعدّاد للأيام والساعات لحد الفرح، و"بقالنا مع بعض" من أول يوم (١ مايو ٢٠٢٦)
- شجرتنا: شجرة بتكبر كل يوم بورقة، ويوم الفرح بتتغطى ورد
- صور بتتغير بالضغط، وعصفورة بلحن، وعروق ورد حوالين الصور
- مرايات طايرة على الأطراف: دوس على أي مراية تكبر وتلف وتطلعلك كلام حلو (٧٠ جملة بتتغير كل مرة)

## أسرع طريقة (من غير أي برامج)
افتح الملف `love-countdown.html` بدبل كليك، هيفتح في المتصفح (Chrome أو Safari) ويشتغل لوحده من غير إنترنت ولا Node.js. ده نفس الصفحة بالظبط بالعصفورة والأغنية.
لو هتفتحه من الموبايل: ابعته لنفسك وافتحه بمتصفح، مش من جوه الشات.

## إزاي تشغّلها كمشروع (للتعديل)
محتاج Node.js (إصدار 18 أو أحدث). مهم: لازم `npm install` الأول، ومينفعش تفتح `index.html` اللي في فولدر المشروع بدبل كليك (ده بيشتغل بس عن طريق `npm run dev`).

```bash
npm install
npm run dev      # تشغيل محلي، افتح الرابط اللي هيطلع
npm run build    # بيطلع نسخة جاهزة للنشر في فولدر dist
npm run build:single   # بيطلع ملف HTML واحد في فولدر dist-single
```

## هيكل المشروع
- `love-countdown.html` النسخة الجاهزة (ملف واحد) تتفتح بدبل كليك
- `src/main.tsx` نقطة البداية
- `src/page.html` و `src/page.css` شكل الصفحة
- `src/love.ts` العدّاد والساعة الرملية والصور والعصفورة
- `src/tree.ts` الشجرة
- `src/words.ts` جمل المرايات (ضيف جمل جديدة براحتك)
- `src/photos/` الصور
- `src/shim/instinct-files.tsx` بديل بسيط لمكتبة المنصة اللي اتبنت عليها الصفحة، بيحفظ الإعدادات في المتصفح (localStorage)
